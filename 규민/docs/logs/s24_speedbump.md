# s24 Phase 4. 고원식 횡단보도 감속 영향 (2026-10-04, 계산만, 서버 없음)

목적: 고원식 횡단보도 한 곳이 주행시간을 얼마나 늘리는지 크기를 안다. 한계를 과장하려는 계산이 아니다

## 1. 입력과 가정

- 목표 속도 v1 = 20 km/h = 5.556 m/s
- 통과 속도 v2 = 10 km/h = 2.778 m/s (가정, 지시문)
- 감속도 a = 3.97 m/s^2 (지시문 값)
  - 검산: 5.556^2 / (2 x 3.89) = 3.967 -> 3.97 맞음
  - 주의(세션21 정정, stops_status 236행·presentation 254행): 3.97 은 실측이 아니다.
    정지거리 3.89m(0.70s x 5.56m/s, 범위 3.78~4.00 의 중간값, 5회 산술 평균은 3.93m)를 처음부터 끝까지 같은 감속도로
    섰다고 가정해 환산한 값이다. 실측 제동 감속도는 6.42 m/s^2(brake 1.0, 정상 구간 회귀)
  - 그래서 본 계산은 지시대로 3.97 을 쓰고, 실측 6.42 와 비교값을 아래에 같이 둔다
- 재가속도 = 감속도와 같다고 가정(실측 없음)
- 고원식 길이 L(10 km/h 를 유지하는 구간) = 가정. 기본 7 m(평탄부 4m + 양쪽 램프 1.5m씩), 비교 4 m / 10 m
  - 차 길이(3.7m, vehicle_bbox 반길이 1.85m x 2)만큼 더 저속을 유지해야 한다고 보면 L 에 3.7m 를 더한다(비교값으로만)
- 비교 기준: 같은 거리를 20 km/h 로 그냥 지나갈 때의 시간

## 2. 계산 (지점 한 곳)

감속 5.556 -> 2.778
- 거리 d = (5.556^2 - 2.778^2) / (2 x 3.97) = (30.864 - 7.716) / 7.94 = 23.148 / 7.94 = 2.915 m
- 시간 t = (5.556 - 2.778) / 3.97 = 0.700 s
- 같은 거리를 20 km/h 로: 2.915 / 5.556 = 0.525 s
- 추가 0.175 s

재가속 2.778 -> 5.556 (감속과 대칭 가정)
- 추가 0.175 s

저속 구간 L
- 추가 = L x (1/2.778 - 1/5.556) = L x (0.360 - 0.180) = 0.180 s/m x L
- L = 4 m: 0.72 s / L = 7 m: 1.26 s / L = 10 m: 1.80 s

합계 (지점당 추가 시간 dT)
- L = 7 m (기본 가정): 0.175 + 0.175 + 1.26 = 1.61 s
- L = 4 m: 1.07 s / L = 10 m: 2.15 s
- L = 0 (순간 통과로 본 하한): 0.35 s
- L = 7 + 3.7 m (차 길이 포함): 0.35 + 1.93 = 2.28 s

감속도를 바꾸면 (L = 7 m)
- 실측 제동 6.42 m/s^2: 감·가속 추가 각 0.108 s -> 합계 1.48 s
- 승차감 수준 1.5 m/s^2 (가정, 실측 아님): 각 0.463 s -> 합계 2.19 s
- 감속도 영향은 작다. 결과를 좌우하는 것은 L(저속 유지 길이)이다

## 3. 지시문 예상과의 차이 (정직하게)

- 지시문 예상: 지점당 0.3~0.5 s
- 계산: 그 범위는 저속 구간 L 을 0~1m 로 볼 때만 나온다(감·가속 두 구간 합 0.35 s)
- 10 km/h 를 고원식 길이만큼 유지하면 그 구간이 지배적이다(7 m 에서 1.26 s). 그래서 기본 가정에서 1.6 s
- 가정을 비튼 것이 아니다. L 가정값을 바꾼 결과를 모두 적었다

## 4. 노선별 영향 (N 은 변수)

- 노선 추가 시간 = N x dT. dT 는 1.1~2.2 s (L 4~10 m), 기본 1.6 s
- 현장 지점 좌표가 아직 없어 노선별 N 은 비워 둔다. 좌표가 생기면 곱하기만 하면 된다
- 참고(크기 감): 노선 주행시간 123~144 s(세션18~20). N = 2 면 약 3 s(약 2~3%), N = 4 면 약 6 s(약 4~5%)
- OSM 에 있는 감속 시설: 양성재 앞 traffic_calming=hump 2곳(s24_offline_checks.md). 그중 하나가 양성재 정차 road r1123 s=40.1 이지만
  양성재 노선은 s=22 에서 서므로 현재 N 에 들어가지 않는다. 태그가 hump 라 현장의 고원식과 같은 것인지 확인 불가

## 5. 결론

- 고원식 횡단보도의 주행시간 영향은 작다(노선당 몇 초 수준). 지점당 약 1.1~2.2 s, 감속 구간만 보면 0.35 s
- 다만 수직 가속도 충격은 전혀 반영되지 않으며, 그쪽이 센서 안정성 측면에서 더 중요할 수 있다
- 맵이 z=0 이므로 둘 다 현재 모델에 없다
- 계산 한계: BasicAgent 가 실제로 10 km/h 까지 줄이고 어디서 다시 가속하는지(세션20 속도 진동 4.1~6.3 m/s 포함)는 반영하지 않았다.
  정속 진동이 ±1 m/s 수준이라 "20 km/h 정속" 기준 자체에 오차가 있다
