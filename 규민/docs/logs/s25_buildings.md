## 주의
1. 중문 궤적이 건물 폴리곤 안을 지난다(확인)
   - 경영대학 본관 N13: 13 tick(0.65s), road1284. 폴리곤 모서리가 차도에 걸침
   - way765358663(이름없음, layer=1): 18 tick(0.85s), road1285·1606. layer=1 은 지면 위 구조물(차가 아래로 지나는 연결 통로 등)일 가능성(추정)
   - 그대로 외곽선 크기 메시를 놓으면 차도를 막는다. 배치 때 폴리곤을 차도에서 떼거나 이 둘은 빼야 한다
2. 외접 사각형은 동서·남북 축 기준이다. 건물이 기울어 있으면 실제 크기보다 크다(s22_buildings.csv 의 len/wid/yaw 는 회전 사각형)
3. 같은 코드 중복: N12(중앙도서관 구관·신관, 정상으로 보임), N10(대학본부·국제교류원). N10 두 건물이 같은 코드인지는 확인 불가
4. U턴 시험 노선은 넣지 않음(지시 5개 노선)

## CSV 열 (s25_buildings.csv)
- osm_type, osm_id: OSM 객체 종류(way)와 번호
- name: 이름(한글, 코드 포함 원문)
- code: 이름에서 뽑은 건물 코드(N13 등). 없으면 빈칸
- ref: OSM ref 태그(이번 범위는 전부 빈칸)
- building: building 태그 값
- levels: building:levels / height_m: height 태그 / layer: layer 태그
- tm_x, tm_y: 지역 TM 중심(꼭짓점 평균, 동 x 북 y, m)
- xodr_x, xodr_y: xodr 좌표 = TM + (521.51, 493.61)
- carla_x, carla_y: CARLA 좌표 = (xodr_x, -xodr_y)
- bbox_ew_m, bbox_ns_m: 외접 사각형 동서 x 남북(m)
- min_dist_m: 5개 노선 궤적에서 외곽선까지 최소 거리
- nearest_route: 그 최소 거리를 낸 노선
- routes_within_100m: 100m 안에 드는 노선과 각 거리(노선:m)
- tier: 1(0~50m) / 2(50~100m) / 0(제외)
- route_inside: 궤적이 폴리곤 안을 지나는 노선
- 정렬: 1순위 -> 2순위 -> 제외, 각 안에서 거리순
