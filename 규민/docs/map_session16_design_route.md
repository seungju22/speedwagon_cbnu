## 코드 설계 (test_drive.py 만 수정)
목적: 주행 로직은 그대로 두고 "어느 경로·어느 종점" 만 선택 가능하게 한다.

1. ROUTES 표(모듈 상수)
   - 이름 -> roads, end_s, connector_junction, sharp_connectors
   - s15: 현재 값 그대로(15 road, 100.38, 커넥터 7, 급회전 3). 재현·대조군
   - r3: s15 와 같은 road/커넥터/급회전, end_s 53.6
   - r1: 위 17 road, end_s 78.4, 커넥터 8(junction 1/107/42/58/44/59/47/51), 급회전 없음
2. select_route(name)
   - 기존 전역 ROUTE_ROADS, LAST_ROAD_END_S, CONNECTOR_JUNCTION, SHARP_CONNECTORS 를 교체
   - ARRIVE_MIN_S = end_s - 5.38 (s15 의 100.38-95.0 간격 유지)
   - 함수들이 전역을 참조하므로 함수 본문은 손대지 않는다
3. 인자 --route {s15,r1,r3}
   - 기본값은 결정 필요(아래)
   - 실행 로그 시작·요약에 route=<이름>, 종점 road/s 출력
   - --sharp-speed 를 r1 과 쓰면 "대상 커넥터 없음" 경고만(오류 아님)
4. dry-plan 파일명: s15 는 drive_plan_dry.csv 그대로(해시 82643554 대조 유지),
   그 외 drive_plan_dry_<route>.csv
5. 불변: CSV 37열, 판정 기준, 속도, 스폰(road1247 공통), 동기 20Hz, --follow
