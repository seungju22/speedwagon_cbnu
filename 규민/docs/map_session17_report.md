## 종점 잔여 약 5m 의 원인
- BasicAgent 도달 판정(base_min_distance 3.0 + 0.5v)이 아니다. 그 값은 중간 웨이포인트 제거 거리이고,
  마지막 웨이포인트는 1m 이내에서만 제거된다(local_planner.py:247)
- 원인은 test_drive.py 자체 완주 조건(913행): road1278 위 s >= ARRIVE_MIN_S(95.0) 이고
  종점(LAST_ROAD_END_S 100.38) 5m 이내. 약 5m/s 에서 거리 조건이 먼저 충족되므로
  실제로는 s >= 95 를 처음 넘는 tick 에서 정지한다
- 검산: 세션17 정지 s=95.40 -> 100.38 - 95.40 = 4.98m / 세션16 s=95.61 -> 4.77m
- 즉 잔여는 설계상 약 5m 이며, 회차 간 차이는 한 tick 이동량(약 0.25m) 안의 위상차
- 참고: 세션16 설계안(map_session16_design_route.md)의 ARRIVE_MIN_S=end_s-5.38 도 같은 구조
