## TTC 임계값 계산 (인용 없음, 우리 차 실측)
- 식: TTC* = t_d + v/(2a). 단 이 차는 명령 직후 속도가 오르는 구간이 있어 식보다 실측 정지거리를 직접 쓰는 쪽이 정확하다
- 제동 부분(작동 지연 포함 실측): 정지거리/명령 속도 최댓값 = 3.94/5.635 = 0.70s (3차 5회 중 최대, 나머지 0.65~0.69s)
  식으로 검산: 0.10s + 6.24/(2x6.27) = 0.60s + 상승 구간 이동분 -> 실측 0.70s 가 더 보수적이라 채택
- 판단 지연: 제어 루프가 한 tick 에 계산해 다음 tick 에 적용 -> 0.05s
- 인지 지연 t_p: 인지 모듈이 없어 미측정(지금은 시뮬 참값 위치 사용, t_p = 0)
- 최소 TTC* = 0.70 + 0.05 + t_p = 0.75s + t_p (20km/h, 평지, brake 1.0 만)
- 목표값 제안: 안전계수 1.5 -> 1.13s + 1.5 t_p. t_p = 0 이면 1.2s(올림). 세션19 제안 1.5s 는 t_p 를 0.25s 까지 허용하는 값
- 한계: 평지에서 잰 값. 내리막 경사 θ 에서는 감속도가 g·sinθ 만큼 준다(예 5% 경사면 약 0.49m/s^2, 6.4 의 약 8%)
