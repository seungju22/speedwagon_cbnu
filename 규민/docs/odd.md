# ODD(운행설계영역) 메모 — 교차로 신호 관련

## 실측 (사용자 직접 확인, 2026-09-15)

- 충북대 개신캠퍼스 교내에 신호등 없음
- 횡단보도 노면표시는 있으나 신호 제어 없음
  (비신호 횡단보도)
- 보행자는 차량이 없으면 임의 지점에서
  횡단하는 것이 일반적 (비정형 보행 패턴)

## OSM 데이터와 대조 (1-4 분석, 2026-09-15)

교내(internal, relation 6705106 폴리곤 기준)
신호등(traffic_signals) 노드: 0개
횡단보도(crossing) 노드: 0개
(전체 캠퍼스+300m 범위 기준: 신호등4개·
횡단보도14개, 전부 외곽도로 상, internal 0)

**신호등 0개 — 실제와 일치.** 교내에 신호등이
없다는 사용자 실측과 OSM 데이터가 그대로
맞아떨어짐. 결손 아님.

**횡단보도 0개 — 데이터 결손.** 사용자 실측상
노면표시가 실제로 존재하므로, OSM에 매핑이
안 되어 있는 것으로 판단. 신호 유무와 무관하게
횡단보도 자체의 매핑 결손.

## 결론

**Osm2Odr의 교차로 신호등 자동생성 옵션
(`generate_traffic_lights`, `all_junctions_
with_traffic_lights`)을 켜지 않는다.**

근거: 이 옵션을 켜면 OSM에 없는 교차로에도
신호등이 자동 생성되는데, 이는 실제 무신호
운행 환경(신호등 없음, 비정형 보행 횡단)과
달라진다. 시뮬레이션이 실제보다 더 통제된
환경을 가정하게 되어 ODD 재현에 어긋남.

적용 시점: Phase 2 osm_to_xodr.py 작성 시
Osm2OdrSettings.generate_traffic_lights = False
(기본값 자체도 확인 필요 — 2-1에서 공식문서로
재확인 후 명시적으로 False 지정)
