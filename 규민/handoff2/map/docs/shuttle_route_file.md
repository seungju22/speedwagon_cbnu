## 좌표계
- 모두 지도 좌표계임. xodr 평면 = Autoware map 좌표(Lanelet2 local_x/local_y). 단위 m
- 방향 yaw_deg 는 x 축에서 반시계로 잰 도. 목표 자세에는 쿼터니언 qz·qw 도 적었음(roll·pitch 0)
- CARLA 좌표로 바꾸려면 (x, -y, -yaw)
- lanelet_id·road_id·s 는 참고용임. Lanelet2 지도를 다시 만들면 ID 가 바뀜. 위치는 x·y 로 찾음

## 승강장 항목
- marker: 승강장 표지. stops_v3 자리의 차선 중심
- door_pose: 정차했을 때 문 가운데 점과 차 방향
- base_link_goal: Autoware 에 줄 목표 자세(뒷바퀴 축 가운데). 표지에서 차로를 따라 1.345m 뒤, 차선 중심
- stop_zone: 차 길이 + 앞뒤 여유, 차선 전폭 다각형
- door_zone: 문 옆 인도 다각형. 정류장 시설 바닥, 차로, 건물은 뺐음
- front_corridor: 차 앞끝부터 차로 안 다각형
- facility: 정류장 시설 바닥(장식 레이어와 같은 자리). 없으면 []
- check.ok: 아래 '검사'를 모두 통과했는지. 도서관 남문(이쪽, lib_south_se)만 false 임
- stoppable/status: lib_south_se 에만 있음. false, '정차 불가: 문 구역 없음(r1369·r1235 위)'. 정차·통과 정류장 어디에도 쓰지 않음

## 가정값과 근거
아래 값은 모두 가정값임. 실제 셔틀 치수·문 위치가 아님(2026-10-13 사용자 결정: 정해질 때까지 그대로 씀).
- 차: Autoware 1.9.0 sample_vehicle(vehicle_info.param.yaml). 길이 4.89, 폭 1.896, 뒷축에서 앞끝 3.79·뒤끝 -1.1
- 문: 오른쪽 옆면, 앞뒤로 차 길이 가운데(EZ10 같은 가운데 문 가정). 뒷축 기준 x +1.345, y -0.948.
  CARLA 프리우스로 재면 x 1.399(0.054m 차)
- 정차 구역 6.89m = 4.89 + 앞 1.0 + 뒤 1.0. I6-2 29쌍이 모두 목표보다 0.44~0.47m 덜 가서 섰음. 그 약 2배
- 문 구역: 앞뒤 3.0m(문 폭 1.2 가정 + 양옆 0.9), 차선 가장자리에서 인도 쪽 1.5m. 시설이 가장자리 0.8m 부터 있어서 시설 있는 승강장은 결과가 0.8 x 3.0m 띠임
- 전방 통로: 앞끝에서 8.0m, 폭 2.5m. 길이는 lanelet 제한속도 20km/h 에서 2.0m/s2(가정)로 서는 거리 7.7m. 폭은 차 폭 + 양쪽 약 0.3m
- 바꾸는 법: map/scripts/s56_shuttle.py 머리의 STOP_MARGIN_*, DOOR_ZONE_*, CORRIDOR_*, DOOR_X 를 고치고 위 순서로 다시 만듦.
  문 위치를 바꾸면 base_link_goal 도 같이 바뀜

## 미션 노드가 쓰는 법
- 도착 목표: 정차 정류장의 base_link_goal 을 Autoware 목표로 줌. 1.9.0 AD API 서비스 /api/routing/set_route_points
  (autoware_adapi_v1_msgs/srv/SetRoutePoints: header frame map, goal, waypoints). 통과 정류장의 via 는 waypoints 에 넣음.
  route 상태는 /api/routing/state. 이미 경로가 있으면 /api/routing/clear_route 뒤에 줌(1.9.0 이미지 routing.hpp 에서 이름 확인)
- 통과 정류장: 요청이 없으면 via 를 경유점으로 넣고 지나감. 요청이 오면 goal_if_requested 를 목표로 주고 섬.
  지금 노선은 통과 정류장을 경유점으로 넣어도 넣지 않아도 같은 길임(경유점이 경로를 바꾸지 않음)
- 도착 판정: /api/routing/state 가 ARRIVED 가 되면 문을 엶. 차 위치가 stop_zone 안인지 같이 보면 좋음
- 출발 조건: 승하차가 끝난 뒤 door_zone 과 front_corridor 안에 사람·물체가 없을 때 출발함.
  물체 위치(인식 결과)를 map 좌표 다각형과 겹침 검사하면 됨. 물체가 정류장 시설 안에 앉아 있는 사람은 door_zone 밖이라 출발을 막지 않음
- 정지 위치 버릇: I6-2 에서 차가 목표보다 약 0.45m 덜 갔음. 문이 표지보다 0.45m 뒤에 서도 door_zone(앞뒤 3.0m) 안임
