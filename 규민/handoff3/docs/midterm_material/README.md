## 클러스터링 비교 (문 구역 장면, 오프라인, tab07)
Autoware 1.9.0 지면 분할 + 유클리드 클러스터링(기본 설정), 보행자 중심 1.0m 안이면 잡음, 10Hz 메시지 기준.

| 점군 | 문 구역 | 전방 통로 | 보행자 점 수(문 / 통로) |
|---|---|---|---|
| 버림 0.45(브리지 LiDAR) | 80/84 95% | 46/51 90% | 124 / 14 |
| 버림 0(기준 LiDAR) | 78/82 95% | 51/51 100% | 223 / 25 |
| 버림 0 + 정류장 시설 점 지움 | 82/82 100% | 51/51 100% | 223 / 25 |

- 통로 놓침은 무작위 버림 탓(점 14개라 최소 10개 밑으로 빠짐), 문 구역 놓침은 보행자가 정류장 시설과 한 덩어리로 붙는 탓
- 시설 점 지움은 오프라인 확인만 했음. 주행은 정답 객체로 하니 지금 넣어도 결과가 안 바뀜. 센서 기반 출발 판단(최종발표)에서 넣음
