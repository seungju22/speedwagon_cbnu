## 문 구역 결과 (나)
- 북문 승강장 정차 뒤 하차 -> 문 구역 5초 -> 전방 통로 들어왔다 나가기 -> 탑승(보행자 도구 ped_tool.py)
- 정차 위치 오차: 문이 목표보다 0.45m 뒤(문 구역 앞뒤 3.0m 안), 옆 0.00m
- 문 구역 안 보행자를 차 시점이 놓친 것은 새로 생긴 보행자의 첫 1틱(0.05s)뿐임(10/15 다시 돌린 회차도 두 보행자 첫 1틱씩, 0.10 / 7.4s). 지붕 LiDAR 가 문 옆 0.3m 까지 맞혀 가까운 쪽 사각이 없음
- 출발 조건(문 구역·전방 통로 비었는지)에 차 시점 인지를 써도 된다는 근거로 쓸 수 있음. 새 물체도 0.1s 안에 들어옴(10/23 고친 뒤)

## 정정 (2026-10-24)
- 위 '첫 1틱(0.05s)'은 정답 노드 자기 기록부터 센 값임. 장면 소환 시각부터 세면 고치기 전 노드는 새 보행자를 0.25~2.1s 늦게 냈음(가짜 서버 시험·10/23 장면, 1초마다 액터 정보를 다시 읽던 탓). 10/23 차 시점 문 구역 놓침 3.4s 가 이것임
- 10/23 에 새 액터를 매 틱 잡게 고침(gt_objects2.py). 소환 -> 처음 낸 시각: 차 시점 0.05~0.10s, 다 보기 0.00~0.05s(보행자 12명, 실제 CARLA)
- 같은 나 장면 차 시점을 다시 달림(s68card): 문 구역 164/166(98.8%), 놓침 0.1s, 전방 통로 102/102
