# 클러스터링 비교 표

원본 perception/docs/perception_demo.md, 회차 기록 integration/docs/s60_report.md 2절

## 실제 LiDAR 클러스터링과 비교 (문 구역, 오프라인, 10/14·10/15)
- 회차 점군을 Autoware 1.9.0 지면 분할(scan_ground_filter) + voxel_grid_based_euclidean_cluster(기본 설정)에 넣고 보행자 정답과 맞췄음(중심 1.0m 안, 10Hz)
- 10/14 는 브리지 LiDAR(무작위 버림 0.45)라 거리 기준(버림 0)과 조건이 달랐음. 10/15 에 같은 장면을 다시 돌리며 같은 자리에 버림 0 기준 LiDAR 를 따로 달아 기록했음

| 점군 | 문 구역 잡음(놓침) | 전방 통로 잡음(놓침) | 보행자 점 수(문 / 통로) |
|---|---|---|---|
| 버림 0.45(10/14) | 74/82 90%(0.8s) | 46/51 90%(0.5s) | 126 / 14 |
| 버림 0.45(10/15) | 80/84 95%(0.4s) | 46/51 90%(0.5s) | 124 / 14 |
| 버림 0(10/15, 기준) | 78/82 95%(0.4s) | 51/51 100%(0) | 223 / 25 |
| 버림 0 + 정류장 시설 점 지움 | 82/82 100%(0) | 51/51 100%(0) | 223 / 25 |

- 전방 통로 놓침은 버림 탓임. 버림 0 이면 보행자 점이 25개라 최소 10점 밑으로 안 떨어짐
- 문 구역 놓침은 버림과 상관없음. 보행자가 정류장 시설(높이 2.3m, 900~1,600점)과 한 클러스터로 붙어 중심이 2m 밀림.
  노선 파일의 시설 자리로 시설 점을 지우면 놓침 0 이 됨(오프라인 확인만, 주행 중 Autoware 에는 안 넣음)
- 차 시점(정답 + 거리·가려짐) 놓침은 문 구역 0.05~0.10s, 전방 통로 0 임. 기준 LiDAR 클러스터링에 시설 점 지움까지 한 경우와 같은 수준이고,
  시설을 안 지운 실제 클러스터링보다는 낙관적임
