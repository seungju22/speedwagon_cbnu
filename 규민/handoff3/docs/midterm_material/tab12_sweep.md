# 표 12. 클러스터 파라미터 쓸기와 LiDAR 밀도 (10/25)

2026-10-25. 같은 부팅·같은 CARLA 에서 거리별 장면(보행자·차·콘 x 5·10·13·15·20·25·30·40m x 차로 가운데·가장자리, 48번)과 나 문 구역 장면을 LiDAR 30만·54.5만 점/s 로 한 번씩 기록함.
