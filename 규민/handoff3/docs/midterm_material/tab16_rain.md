# 표 16. 비 조건 인지 (10/25, P6)

2026-10-25. 10/25 같은 CARLA bag(54.5만, 거리별 48번·북문 나 장면)에 점군 열화를 넣어 오프라인으로 다시 돌림. 건물 점 지움, 최소 점 5, 시드 0.
열화는 Goodin et al. 2019(Electronics 8(1) 89) 식 8(세기 감소, 문턱 밑 점 지움)·식 9(거리 잡음 최대 2%). 표적 ρ 0.07(식 3 의 후방 산란 계수, ρ = r/π 라 반사율 약 22%), 맑을 때 최대 거리 100m 가정. 비1 9mm/h, 비2 25mm/h.
CARLA 0.9.15 LiDAR 속성에는 날씨 연결이 없어 CARLA 날씨 대신 우리 노드에서 열화함.

### 같은 시드 두 번: 거리별 json 같음(처리 시간 칸 뺌), 문 구역 json 같음

- 15km/h 정지 거리 12.9m 안쪽 검출은 세 조건 같음. 모델 최대 거리(비1 21.9m, 비2 16.2m)가 12.9m 보다 멀어서
- 먼 쪽만 줄어듦: 차 90% 거리 25 -> 20 -> 15m, 보행자 20m 39 -> 32 -> 0%
- 거짓 객체 증가는 거리 잡음이 건물 벽 점을 지움 사각형 밖으로 민 것. 차 앞 차로 안은 그대로
- 같은 시드 두 번 같은 숫자
- 실제 센서·실제 비로 잰 값이 아님. 가정값을 바꾸면 숫자가 바뀜
